# Device tree for Xiaomi POCO F4 / Redmi K40S (munch)

The Xiaomi POCO F4 / Redmi K40S (codenamed _"munch"_) is a high-end smartphone from Xiaomi.

It was announced in February 2022 (Redmi K40S) and June 2022 (POCO F4).

## Device specifications

| Basic                   | Spec Sheet                                                    |
| -----------------------:|:------------------------------------------------------------- |
| SoC                     | Qualcomm SM8250-AC Snapdragon 870 5G                          |
| CPU                     | Octa-core (1x3.2 GHz Kryo 585 & 3x2.42 GHz Kryo 585 & 4x1.80 GHz Kryo 585) |
| GPU                     | Adreno 650                                                    |
| Memory                  | 6/8/12 GB RAM                                                 |
| Storage                 | 128/256 GB UFS 3.1                                            |
| Display                 | 6.67" 1080 x 2400 AMOLED, 120 Hz                              |
| Battery                 | 4500 mAh, 67 W fast charging                                  |
